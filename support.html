FloatClip / Support

Support

Questions, troubleshooting and feedback for the Portable and Microsoft Store editions.

Reporting a problem

Please include the FloatClip version, Store or Portable edition, Windows version, and steps to reproduce the issue. A screenshot may help, but remove sensitive or personal information first.

Clipboard History

FloatClip opens the Windows Clipboard History interface with Win+V. This Windows feature may need to be enabled in system settings. FloatClip does not have its own clipboard history.

Store vs Portable

Portable v1.0.0 is available now: official GitHub release (SHA256SUMS). The Microsoft Store edition is currently in certification and not yet public.

In the Store edition, Start with Windows and Restart as administrator are intentionally unavailable inside FloatClip. The Portable edition retains those optional features.

Privacy questions

See our privacy policy or contact support directly.
