Reporting a problem

Please include the FloatClip version, Store or Portable edition, Windows version, and steps to reproduce the issue. A screenshot may help, but remove sensitive or personal information first.

Clipboard History

FloatClip opens the Windows Clipboard History interface with Win+V. This Windows feature may need to be enabled in system settings. FloatClip does not have its own clipboard history.

Store vs Portable

In the Store edition, Start with Windows and Restart as administrator are intentionally unavailable inside FloatClip. The Portable edition retains those optional features.

Prijava težave

Navedite različico FloatClipa, Store ali Portable izdajo, različico Windows in korake za ponovitev napake. Posnetek zaslona lahko pomaga, vendar prej prekrijte osebne in občutljive podatke.

Zgodovina odložišča

FloatClip odpre Windows Clipboard History z Win+V. Funkcijo morate po potrebi omogočiti v sistemskih nastavitvah. FloatClip nima svoje zgodovine odložišča.

Store in Portable

V Store izdaji sta možnosti Start with Windows in Restart as administrator znotraj aplikacije namenoma nedostopni. Portable izdaja ju ohranja kot neobvezni funkciji.
