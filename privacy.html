What FloatClip does

FloatClip is a native Windows 11 desktop utility. It sends standard keyboard shortcuts to the active application for actions such as Copy and Paste. It does not maintain its own clipboard history or upload clipboard contents.

Data collected by the application

FloatClip does not have developer-operated accounts, cloud synchronization, advertisements, analytics, or telemetry. It does not intentionally collect or transmit personal information, clipboard contents, screenshots, or usage reports to machinefhead.

For interface behavior, FloatClip may observe Windows notifications about clipboard changes or whether a clipboard format is available. This is not a record of copied content.

Settings kept on your device

Preferences such as theme, language, window position, opacity, and docking behavior are stored locally in an INI file. The Portable edition uses %LOCALAPPDATA%\FloatClip\settings.ini. The Microsoft Store edition uses a separate logical settings location under %LOCALAPPDATA%\FloatClipStore, subject to Windows package redirection.

The Portable edition can optionally register Start with Windows for the current Windows user. The Microsoft Store edition does not manage that startup setting or offer in-app administrator restart.

Windows features and external services

Windows Clipboard History (Win+V), screen snipping, and Windows Settings are operating system features. Their handling of information is governed by Windows and the applications you use, not by a FloatClip cloud service.

Support email

If you choose to email support, your email address and any information you provide are used to read and respond to your request. Avoid sending passwords, sensitive clipboard content, or unredacted screenshots. Support correspondence is handled through Proton Mail; its email service has its own privacy terms. You can request deletion of your support correspondence, subject to applicable requirements.

This website

These pages contain no FloatClip analytics scripts, advertising trackers, or site-set cookies. If hosted on GitHub Pages, GitHub processes technical information about visits, including IP addresses for security. See the GitHub Privacy Statement.

Changes and contact

This policy may be updated when FloatClip changes. The date above indicates its latest revision. Privacy inquiries: floatclip.support@proton.me.

Slovenščina — pravilnik zasebnosti

Kaj počne FloatClip

FloatClip je izvorni namizni pripomoček za Windows 11. Aktivni aplikaciji pošilja običajne bližnjice na tipkovnici za kopiranje, lepljenje in podobna dejanja. Ne vzdržuje lastne zgodovine odložišča in ne nalaga vsebine odložišča v oblak.

Podatki, ki jih zbira aplikacija

FloatClip nima uporabniških računov pri razvijalcu, sinhronizacije v oblak, oglasov, analitike ali telemetrije. Namenoma ne zbira in ne posreduje osebnih podatkov, vsebine odložišča, posnetkov zaslona ali poročil o uporabi založniku machinefhead.

Zaradi delovanja uporabniškega vmesnika lahko spremlja sistemska obvestila Windows o spremembi odložišča ali razpoložljivosti določenega formata. To ne pomeni beleženja kopirane vsebine.

Lokalno shranjevanje nastavitev

Nastavitve teme, jezika, položaja, prosojnosti in pripenjanja se hranijo lokalno v datoteki INI. Portable izdaja uporablja %LOCALAPPDATA%\FloatClip\settings.ini; Store izdaja ima ločeno logično lokacijo v %LOCALAPPDATA%\FloatClipStore, ki je lahko podvržena preusmerjanju datotek MSIX.

Portable izdaja lahko na uporabnikovo zahtevo nastavi zagon z Windows za trenutnega uporabnika. Store izdaja te možnosti in ponovnega zagona s skrbniškimi pravicami znotraj aplikacije nima.

Sistemske funkcije

Zgodovina odložišča Windows (Win+V), izrezovanje zaslona in Windows Settings so funkcije operacijskega sistema. Zanje veljajo pravila Microsofta ter programov, ki jih uporabljate, ne pa oblačne storitve FloatClip.

E-pošta za podporo

Če podpori prostovoljno pošljete sporočilo, vaš e-poštni naslov in posredovane podatke uporabimo za obravnavo in odgovor. Ne pošiljajte gesel, občutljive kopirane vsebine ali neprekritih zasebnih posnetkov. E-poštno komunikacijo obdeluje Proton Mail po svojih pravilih zasebnosti. Zahtevate lahko izbris podporne korespondence ob upoštevanju veljavnih obveznosti.

To spletno mesto

Te strani ne vsebujejo FloatClip analitike, oglasnih sledilnikov ali piškotkov, ki bi jih nastavilo spletno mesto. Če gostujejo na GitHub Pages, GitHub obdeluje tehnične podatke o obiskih, vključno z IP-naslovi zaradi varnosti. Glejte GitHubov pravilnik zasebnosti.

Spremembe in kontakt

Pravilnik se lahko ob spremembah FloatClipa posodobi. Zgoraj je naveden datum zadnje spremembe. Vprašanja o zasebnosti: floatclip.support@proton.me.
