Privacy & data

Privacy policy

How FloatClip handles local settings, Windows clipboard actions, support messages and this website.

Publisher: machinefhead · Last updated: 8 November 2026

What FloatClip does

FloatClip is a native Windows 11 desktop utility. It sends standard keyboard shortcuts to the active application for actions such as Copy and Paste. It does not maintain its own clipboard history or upload clipboard contents.

Data collected by the application

FloatClip does not have developer-operated accounts, cloud synchronization, advertisements, analytics, or telemetry. It does not intentionally collect or transmit personal information, clipboard contents, screenshots, or usage reports to machinefhead.

For interface behavior, FloatClip may observe Windows notifications about clipboard changes or whether a clipboard format is available. This is not a record of copied content.

Settings kept on your device

Preferences such as theme, language, window position, opacity, and docking behavior are stored locally in an INI file. The Portable edition uses %LOCALAPPDATA%\FloatClip\settings.ini. The Microsoft Store edition uses a separate logical settings location under %LOCALAPPDATA%\FloatClipStore, subject to Windows package redirection.

The Portable edition can optionally register Start with Windows for the current Windows user. The Microsoft Store edition does not manage that startup setting or offer in-app administrator restart.

Windows features and external services

Windows Clipboard History (Win+V), screen snipping, and Windows Settings are operating system features. Their handling of information is governed by Windows and the applications you use, not by a FloatClip cloud service.

Support email

If you choose to email support, your email address and any information you provide are used to read and respond to your request. Avoid sending passwords, sensitive clipboard content, or unredacted screenshots. Support correspondence is handled through Proton Mail; its email service has its own privacy terms. You can request deletion of your support correspondence, subject to applicable requirements.

This website

These pages contain no FloatClip analytics scripts, advertising trackers, or site-set cookies. If hosted on GitHub Pages, GitHub processes technical information about visits, including IP addresses for security. See the GitHub Privacy Statement.

Changes and contact

This policy may be updated when FloatClip changes. The date above indicates its latest revision. Privacy inquiries: floatclip.support@proton.me.
