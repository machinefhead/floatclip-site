# FloatClip

**Copy & Paste. Right where you work.**

FloatClip is a lightweight native **Windows 11 x64** utility with a movable floating Copy/Paste toolbar. It offers Standard and Single modes, mouse gestures, system tray controls, Free / Snap / Auto-hide, optional Edge Follow, themes, transparency settings and a three-step Quick Intro.

**Release:** v1.0.0 — Microsoft Store certification/publication pending. No official public download is linked from this website yet.  
**Publisher:** machinefhead · **Price:** free proprietary software  
**System:** Windows 11 x64; ARM64 not independently validated  
**App languages:** 10 text UI localizations (English default). **Site / Store listing languages:** English and Slovenian.

FloatClip operates locally, does not require a developer account or cloud service, and has no advertising, analytics, or telemetry. It does not maintain its own clipboard-history database. See the privacy policy for details.
